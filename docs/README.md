## Deployment quick links
- Backend (Render): set repo root, service rootDir = `backend`, start = `uvicorn app.main:app --host 0.0.0.0 --port $PORT`.
- Frontend (Vercel): set env `NEXT_PUBLIC_API_BASE` to backend URL.
