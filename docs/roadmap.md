# Roadmap — Nomad AI

## Now (MVP)
- Smart Itinerary Builder
- Travel Signals (deals/events)
- Memory Journal
- Weekly Email Digest

## Next 1–2 months
- Auth + user profiles
- Saved searches and digest preferences
- Multi-city trip planning and transit suggestions
- Surprise Mode enhancements (seasonal picks, niche themes)

## 3–6 months
- Social trip sharing and collaborative planning
- Offline-capable mobile PWA
- GPT-OSS fine-tune for travel Q&A and preference memory
- Integrations with free/open APIs for weather, public transit, and events

## Premium (opt-in)
- Personal AI travel model with long-term memory
- Advanced deal alerts and price tracking
- Export to Google/Apple Calendar
- AI concierge chat with voice
